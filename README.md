# フラッシュ暗算

本项目是一个“フラッシュ暗算”的复刻版网页练习应用。

## 缘起

制作本项目的起因是看到了文野环 (文野環) 的一场直播实况，她在直播中挑战了这款经典的フラッシュ暗算游戏并展现了极佳的节目效果。为了能在现代环境中拥有更佳、更护眼的练习体验，我们将其重制为了这个纯静态页面。

📺 **相关直播出处**: [【耐久】フラッシュ暗算しながら歌い計算ミスするたびに赤裸々エピソード暴露する配信【にじさんじ】【文野環/野良猫】](https://www.youtube.com/watch?v=Mi881lL3E2A)

## 特性

- **开箱即用**：纯 HTML + CSS + Vanilla JS 构建。零依赖、无构建步骤（No Build Step）。
- **暗黑护眼模式**：默认采用深色主题，保护视力。
- **高还原度**：UI 排版尽力复刻了直播中那种长条形的红绿大边框，并且内部计时的毫秒级控制算法也与原版保持一致。
- **移动端友好**：自带响应式布局（Responsive Layout），无论是 PC 还是手机均可完美浏览。

## 部署与运行

由于它仅是一个静态单文件 `index.html`，你可以：
1. **本地运行**：直接在资源管理器双击 `index.html` 在浏览器中打开游玩。
2. **线上托管**：将其直接拖入 Cloudflare Pages、Vercel 或 GitHub Pages，即可一键完成部署。
